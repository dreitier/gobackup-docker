## [2.0.0](https://github.com/dreitier/gobackup-docker/compare/v1.0.1...2.0.0) (2026-11-14)

### ⚠ BREAKING CHANGES

* interpolator and the entrypoint script are gone. Mount
the config to /etc/gobackup/gobackup.yml (gobackup expands ${VARS}
itself), use `schedule:` with the default `run` command or `perform`
instead of `cron "<expression>"`, and note that the container runs as
UID 1000.

### Features

* migrate to official gobackup release and drop interpolator ([aface16](https://github.com/dreitier/gobackup-docker/commit/aface16b8c81d86d52ab63d76abcd454820747d9))
* run gobackup v3 natively and automate releases ([#2](https://github.com/dreitier/gobackup-docker/issues/2)) ([09a4db0](https://github.com/dreitier/gobackup-docker/commit/09a4db01830a7ec80ef9fcb4072e21fe876e391d))

## [0.20220713.0] - 2022-07-13
### Added
- GitHub Actions workflow has been added
- On a tag push for this repository, a Docker image will be created and pushed to https://hub.docker.com/repository/docker/dreitier/gobackup.

### Changed
- `gobackup` base image is now based upon Fedora 36 and the latest MongoDB utilities.
- Instead of building `gobackup` and `interpolator` on our own, we are using the existing artifacts (binary releases for gobackup, binary from the interpolator Docker image).
